# CareerQuest AI

대전 소재 대학생을 대상으로 **전국 채용시장의 요구 역량을 분석하고, 부족한 역량을 대전 지역의 교내외 성장 기회와 연결하는 AI 기반 커리어 성장 가이드**입니다.

## 프로젝트 목표

대학생은 희망 직무를 정해도 실제 채용공고에서 어떤 역량이 반복적으로 요구되는지, 그리고 현재 자신에게 어떤 역량이 부족한지 파악하기 어렵습니다. 또한 대학 비교과 프로그램, 지역 청년지원 사업, 교육·공모전·인턴십 정보가 여러 기관에 분산되어 있어 자신에게 필요한 활동을 직접 찾아야 합니다.

CareerQuest AI는 다음 흐름으로 이 문제를 해결하고자 합니다.

**전국 채용시장 요구 역량 → 학생 보유 역량과 비교 → 부족 역량 분석 → 대전 지역에서 참여 가능한 활동 추천**

학생의 취업 지역을 대전으로 제한하지 않고, 대전에서 대학생활을 하는 동안 활용할 수 있는 지역 자원을 연결하여 전국 어디든 원하는 진로로 성장할 수 있도록 지원하는 것이 목표입니다.

## 주요 기능

- 전공, 학년, 희망 직무, 자격증, 프로젝트·활동 경험 기반 학생 프로필 구성
- 실제 채용공고에서 직무별 요구 기술·자격·경험 분석
- 학생 보유 역량과 채용시장 요구 역량의 Gap 분석
- 부족한 역량을 보완할 수 있는 비교과 프로그램, 교육, 공모전, 인턴십 등 추천
- 추천 결과를 '다음 퀘스트' 형태로 제공
- 실제 공고와 프로그램 정보를 근거로 설명하는 RAG 기반 추천

## 데이터 활용 계획

프로젝트에서는 공개적으로 제공되는 채용정보 API와 대학·지역기관의 공개 정보를 활용할 계획입니다.

- 채용정보: 사람인 채용정보 API 등 공식 API 활용 검토
- 대학 정보: 건양대학교 등 대학의 공개 비교과·취업·장학·학사 정보
- 지역 정보: 대전 지역 청년지원, 교육, 공모전, 인턴십 및 기관 프로그램
- 비정형 문서: 공개 PDF/HWP 및 웹 문서를 RAG 검색용 데이터로 활용

채용정보는 직무·지역·경력·학력·직무 키워드 등의 분석 목적으로 사용하며, 서비스에서 활용할 경우 **데이터 출처와 원문 링크를 명시**할 예정입니다.

## AI 활용 구조

1. API 및 웹 크롤링을 통해 공개 데이터 수집
2. 정형 데이터는 DB에 저장
3. 공고·프로그램 상세 설명 등 비정형 텍스트는 임베딩 후 Vector DB에 저장
4. RAG를 통해 사용자 목표와 관련된 실제 문서를 검색
5. LLM이 학생 보유 역량과 채용시장 요구 역량을 비교하여 부족 역량을 분석
6. 부족한 역량을 보완할 수 있는 대전 지역 활동을 추천

## 현재 개발 단계

현재는 프로젝트 기획 및 데이터 수집·정제 단계로, 대학 공개 데이터를 대상으로 웹 크롤링 프로토타입을 제작하고 RAG 실습용 문서 데이터를 구축하고 있습니다. 이후 채용정보 API 연동, 공통 데이터 구조 설계, Vector DB 구축, Gap 분석 및 추천 기능을 단계적으로 구현할 예정입니다.
